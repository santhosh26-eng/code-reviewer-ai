# Contributing to Code Reviewer and Explainer

Thank you for your interest in contributing to this capstone project!

To maintain a high standard of code quality, please adhere to the following guidelines:

- **Create a feature branch:** Always branch off `master` when adding a new feature or fixing a bug.
- **Make focused commits:** Keep your commits small and logically grouped. One commit = one feature or fix.
- **Test before committing:** Ensure all tests pass (`pytest`) before committing your code.
- **Never commit secrets:** Double-check that `.env` and other secret files are not staged.
- **Use meaningful commit messages:** Refer to the `docs/GIT_WORKFLOW.md` for our standardized commit convention.
